#  dodep — рулетка для VS Code

Расширение для Visual Studio Code, которое открывает интерактивную рулетку
с числами от 0 до 10 и выдаёт случайный «вердикт» в стиле мемного трейдинга.
Плагин создан в рамках лабораторной работы по теме «Создание плагина».

## Описание

**dodep** — это развлекательное расширение, которое комбинацией клавиш
открывает панель с анимированной рулеткой. После остановки рулетка
показывает выпавшее число и соответствующую ему фразу.

Плагин демонстрирует возможности VS Code Extension API:

- регистрацию пользовательских команд;
- создание собственной панели через **Webview**;
- работу с **горячими клавишами** (keybindings);
- внедрение произвольных HTML/CSS/JavaScript-интерфейсов внутрь редактора.

### Возможности

- **Анимированная рулетка** — числа от 0 до 10 с эффектом «прокрутки».
- **Сочетание клавиш** — `Cmd+Shift+T` →  на macOS, `Ctrl+Shift+T` → на Windows/Linux.
- **Кнопка «Крутить»** — позволяет запускать рулетку повторно без закрытия окна.
- **Четыре исхода** в зависимости от выпавшего числа:

| Число | Сообщение |
| :---: | :--- |
| **0** | «Ты проиграл квартиру» |
| **1–5** | «Нужен додеп» |
| **6–9** | «Депай всё, что есть» |
| **10** | «Красавчик, но все ещё нужен додеп» |
